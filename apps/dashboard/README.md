# SightHog Dashboard

Next.js analytics dashboard with Tremor charts and rrweb session replay.

See the [root README](../../README.md#phase-3-dashboard-and-replay-player) for architecture, URLs, and verification steps.

**Local dev:** `npm run dev` (port 3000). Requires Postgres, ClickHouse, and SeaweedFS — easiest via `docker compose up` from the repo root.
